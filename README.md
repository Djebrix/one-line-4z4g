# One Line, One Laugh

Entry for [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) — a single funny line, judged pairwise by a judge model.

> I told my Roomba it was adopted. Now it only vacuums the neighbour's house.

## Run

```sh
python3 main.py
cat "$ENTRY_OUTPUT_DIR/entry.txt"  # defaults to /output/entry.txt
```

`main.py` uses only the Python standard library, makes no network calls, and
is fully deterministic: repeated runs produce byte-identical output.
